# LA-310

Синтетичний навчальний набір MXMT із 310 SKU, 30 брендами, 20 категоріями, чотирма каналами й шістьма демопостачальниками. Товари, ціни, продажі, повернення, надходження й залишки змодельовано для вправ із мерчандайзингу. Категорії мають українські й англійські назви. Історія руху починається 1 січня 2025 року. Дата останнього спостереження для цього випуску — 21 листопада 2026 року за Києвом.

Запаси містять щоденні спостереження за останні 32 дні та спостереження на кінець попередніх місяців. Для K2 є всі 30 потрібних днів. За межами щоденної історії швидкість продажів використовує штатний розрахунок на основі підтверджених надходжень.

Щоб відтворити цей випуск, запустіть із кореня репозиторію:

```sh
python3 'docs/maup/диплом/LA-310/build_fixture.py' --end 2026-11-21
```

Генератор перевіряє унікальність товарів і подій, зв’язок повернень із продажами та баланс запасів. Контрольні значення за 1–21 листопада збережено в полі `controls` файлу JSON. Ізольована перевірка охопила п’ять екранів, порівняння рік до року, історію запасів K2 та обидва сценарії.
